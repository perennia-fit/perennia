This file applies to `GetReady.caf`, `PrepareBeep.caf` and `TimerComplete.caf`
in this directory — pure synthesized sine tones generated by
`tools/gen-timer-sounds.mjs`, dedicated to the public domain under CC0 1.0
(https://creativecommons.org/publicdomain/zero/1.0/). `GetReady.caf` is two
120 ms, 660 Hz notes, 120 ms apart; `PrepareBeep.caf` is three 90 ms, 1200 Hz
blips starting at 0, 1000 and 2000 ms. See the fuller note at
`apps/mobile/android/app/src/main/timer_sounds.LICENSE.md`.
