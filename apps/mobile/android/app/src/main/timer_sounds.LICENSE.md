SPDX-License-Identifier: CC0-1.0

This file applies to the timer cue assets in this directory
(`prepare_beep.ogg`, `timer_complete.ogg`) and their iOS counterparts under
`apps/mobile/ios/Runner/Sounds/` (`PrepareBeep.caf`, `TimerComplete.caf`). The
application source code in the rest of the repository is licensed separately by
the repository root `LICENSE`.

These are not third-party recordings. They are pure synthesized sine tones
generated by `tools/gen-timer-sounds.mjs` — a fixed sequence of short blips (the
3-2-1 prepare cue) and a two-note rising chirp (the completion cue). As
machine-generated tones with no creative authorship claimed, they are dedicated
to the public domain under Creative Commons Zero (CC0 1.0), the closest
equivalent to "no rights reserved":
https://creativecommons.org/publicdomain/zero/1.0/

## Regeneration

Run `node tools/gen-timer-sounds.mjs` from the repository root. The committed
`.ogg` (Android) and `.caf` (iOS) files are transcoded from intermediate WAVs
via ffmpeg; the exact ffmpeg invocations are documented in the script header.
