This file applies to the timer cue assets in this directory
(`get_ready.ogg`, `prepare_beep.ogg`, `timer_complete.ogg`) and their iOS
counterparts under `apps/mobile/ios/Runner/Sounds/` (`GetReady.caf`,
`PrepareBeep.caf`, `TimerComplete.caf`). The application source code in the rest
of the repository is licensed separately by the repository root `LICENSE`.

These are not third-party recordings. They are pure synthesized sine tones
generated by `tools/gen-timer-sounds.mjs`:

- the get-ready cue: two 120 ms, 660 Hz notes, 120 ms apart;
- the 3-2-1 prepare cue: three 90 ms, 1200 Hz blips starting at 0, 1000 and
  2000 ms;
- the completion cue: a two-note rising chirp.

As machine-generated tones with no creative authorship claimed, they are
dedicated to the public domain under Creative Commons Zero (CC0 1.0), the closest
equivalent to "no rights reserved":
https://creativecommons.org/publicdomain/zero/1.0/

## Regeneration

Run `node tools/gen-timer-sounds.mjs` from the repository root, with ffmpeg on
PATH. The committed `.ogg` (Android) and `.caf` (iOS) files are transcoded from
intermediate WAVs, which the script deletes; the exact ffmpeg invocations are
documented in the script header.
